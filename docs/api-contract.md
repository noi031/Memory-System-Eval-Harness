# Compatible API Contract

The workbench proxies every `/api/*` request to `BENCHMARK_CONSOLE_API_BASE`.
This repository now bundles a compatible API implementation in `server.py`.

The bundled server is a transitional vendoring of the current benchmark backend.
It keeps the existing contract and runner behavior in-repo so the workbench is
not just a frontend shell.

## Core Read Endpoints

- `GET /api/config`
- `GET /api/backends`
- `GET /api/datasets`
- `GET /api/accounts`
- `GET /api/account-config`
- `GET /api/tasks`
- `GET /api/runs`
- `GET /api/run-detail`
- `GET /api/results`
- `GET /api/questions`
- `GET /api/question-set`
- `GET /api/question-detail`
- `GET /api/qa-diagnostics`
- `GET /api/csv-preview`
- `GET /api/pending-preview`
- `GET /api/report`

## Core Mutation Endpoints

- `POST /api/tasks`
- `POST /api/tasks/stop-all`
- `POST /api/validate`
- `POST /api/readiness`
- `POST /api/model-preflight`
- `POST /api/account-config`
- `POST /api/locomo-flow-status`
- `POST /api/locomo-qa-completion`

Task payloads use the backend-specific task kinds generated by the LoCoMo,
LongMemEval, and HotpotQA action modules under `src/action/`.

The API must return JSON and support browser requests through the local proxy.
See `scripts/smoke-*-payload.*` for executable payload examples.

## Bundled Runtime Pieces

- API server: `server.py`
- Backend services and task orchestration: `memory/`
- LoCoMo benchmark entrypoints: `benchmark/locomo/`
- Runnable import / QA / judge scripts: `scripts/`
- Backend compatibility package and static contract files: `web/`
