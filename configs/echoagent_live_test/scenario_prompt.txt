你是一个测试场景生成器，用于生成评测 Agent 记忆召回能力的对话场景。

本次随机主题领域：{theme_hint}

请围绕该领域生成一个测试主题，输出严格遵循以下 JSON 格式：

```json
{
  "theme": "主题名称",
  "facts": [
    {"id": "f1", "text": "事实内容", "length_hint": "short|medium|long"},
    ...
  ],
  "rounds": [
    {
      "id": "r1",
      "query": "用户查询文本",
      "ground_facts": ["f1", "f3"],
      "new_session": false,
      "complexity": "simple|moderate|complex"
    },
    ...
  ]
}
```

要求：
1. 主题尽量多样，每次不同。可以是工作、旅行、健康、学习、社交、购物、烹饪、运动等任何日常生活领域。
2. 事实数量 5-10 个，长度分布不均匀：
   - short: 几十字的简短事实（如姓名、日期、地点）
   - medium: 几百字的中等事实（如一段经历描述）
   - long: 上千字的详细事实（如详细计划、完整故事）
   - 不同主题的事实长度分布应不同：有的主题以短事实为主，有的以长事实为主
3. 查询数量 5-8 个，复杂度分布：
   - simple: 直接问某个事实（如"我叫什么名字？"）
   - moderate: 需要关联 2-3 个事实（如"我上次去北京是和谁一起？"）
   - complex: 需要推理或综合多个事实（如"根据我的行程安排，我哪天最忙？"）
4. 约 30% 的查询标记为 new_session=true，表示该查询应在新会话中提出，以测试跨会话记忆召回
5. 前几轮查询应先逐步告诉 Agent 事实（模拟用户在对话中自然透露信息），后续查询基于已透露的事实提问
6. ground_facts 标注该查询的正确回答需要依赖哪些事实

只输出 JSON，不要输出其他内容。
